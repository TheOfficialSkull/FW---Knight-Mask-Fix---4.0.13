\# FlexWayne - Face The Knight Mask Fix (+ Armor Variant)



\*\*Fixes Death Knight mask texture issue on Knight PMC and player character.\*\*



\## Versions

\- \*\*Mask Fix Only\*\*: Pure texture fix (true-to-vanilla feel).

\- \*\*Knight + Armor\*\*: Mask fix + configurable armor (Level 4 Titan by default).



\*\*Credits\*\*: Based on Umbigo Preto's original mod. All credit to him for the core fix. (Link to his GitHub/Forge page)



\## Installation

1\. Choose one version only.

2\. Extract the contents directly into your SPT root folder (drag `FaceTheKnightMaskFix/` or renamed folder).

3\. (For +Armor) Edit `user/mods/.../config/config.json`.



\## Configuration (Knight + Armor only)

```json

{

&#x20; "ArmorClass": 4,

&#x20; "Durability": 85,

&#x20; "ArmorMaterial": "Titan"
